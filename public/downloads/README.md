# FTWSentinel Minecraft Plugin

Place the compiled `FTWSentinel.jar` file in this directory.

## Build Instructions

1. Navigate to the root of the project
2. Run the compilation script:
   - Windows: `compile.bat`
   - Linux/Mac: `./compile.sh`
3. Copy the generated `FTWSentinel.jar` to this directory

## File Structure

```
public/downloads/
└── FTWSentinel.jar  (place compiled JAR here)
```

The download endpoint will serve this file to authenticated users.
